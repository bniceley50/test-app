## Secondary Sources

### 5. International Plumbing Code (IPC) 2018/2021
- **URLs**: https://codes.iccsafe.org/content/IPC2021P3, https://codes.iccsafe.org/content/Ipc2018
- **Classification**: SECONDARY
- **What it contains**: Full IPC code. KY's code shares lineage with IPC but is NOT the IPC.
- **Allowed for production seeds**: ONLY if a specific IPC provision is confirmed to match KY code
- **Risk**: Many IPC rules differ from KY code (e.g., IPC allows wet venting, KY does NOT)
